Fixes for 1.3.0.

- A setup opens with each player and timing window on the board it was saved on. In 1.3.0, windows could go to the wrong board, depending on the order in which they opened.
- A setup always opens on board 1.
- Pinboard remembers the boards of your last session. MultiViewer opens that session again when it starts.
- Close Pinboard from the taskbar or with Alt+F4: Pinboard asks the same question as Exit, unless you chose "Don't ask again".
